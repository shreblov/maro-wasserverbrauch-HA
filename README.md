Dieses Repository enthält die Anleitung und die Quellen, um den Wert für den Wasserverbrauch der Maro Model 1 von der Maro Home Webseite auszulesen. Wenn der aktuelle Wasserverbrauch höher als ein eingestellter Grenzwert ist, wird eine Benachrichtigung an Signal geschickt. 
## Voraussetzungen
Home Assistant, Maro Home Account, Maro Model 1 in Maro Home eingebunden.
